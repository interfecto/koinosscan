# koinosscan

Open-source tools behind [koinosscan.com](https://koinosscan.com).

| Folder | What it is |
|---|---|
| [`koindx-gt-adapter`](koindx-gt-adapter/) | Reads KoinDX pools and their swaps, joins and exits from Koinos blocks and serves them in the GeckoTerminal adapter format. No dependencies, Node.js 20+. |
